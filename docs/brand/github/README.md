# GitHub images

Images for the parts of GitHub that are set in its settings, not by files in the repository. Both use the dashboard logo and the Aurora app icon.

| File | Size | Where to set it |
|---|---|---|
| `social-preview.png` | 1200 x 630 | Repository, Settings, General, Social preview, Upload an image |
| `avatar-512.png` | 512 x 512 | Organization or profile, Settings, Profile picture |

The README itself already uses the same logo files from `docs/brand/aurora/svg/`.
