# Supermetry brand kit

The Supermetry logo is the **Aurora** mark: three flowing bands that rise from left to right, shaded from violet through blue to green, next to the lowercase wordmark `supermetry`.

## Files

| Use | File |
|---|---|
| Logo with wordmark on a light background | `aurora/svg/supermetry-logo-on-light.svg` |
| Logo with wordmark on a dark background | `aurora/svg/supermetry-logo-on-dark.svg` |
| Mark alone on a light background | `aurora/svg/supermetry-mark.svg` |
| Mark alone on a dark background | `aurora/svg/supermetry-mark-on-dark.svg` |
| App icon (rounded square, dark) | `aurora/svg/supermetry-aurora-appicon.svg`, `aurora/png/supermetry-aurora-appicon.png` (1024 px) |
| Transparent mark, raster | `aurora/png/supermetry-aurora-icon.png` (1024 px) |
| Wide lockup on deep space blue, raster | `aurora/png/supermetry-aurora-lockup.png` (2400 x 900) |
| Uncropped 512 px design masters | `aurora/source/` |

The four SVGs in `aurora/svg/` besides the app icon are the files the dashboard ships. They are copies of `web/public/brand/`, so change both together. The favicons (`favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`) live in `web/public/`.

`concepts/` holds the logo directions that were considered and not chosen. They are kept for reference and are not part of the brand.

## Color

| Surface | Gradient stops, start to end |
|---|---|
| Light backgrounds | `#6d3cf0`, `#1f6fe8`, `#0a93b8`, `#0f9a6c` |
| Dark backgrounds | `#8a5cff`, `#2f8bff`, `#6ff6ff`, `#7dffc4` |
| App icon background | `#05091e` to `#0c1440` |

## Usage

- Pick the light or dark file to match the background; do not place the light mark on a dark surface.
- The wordmark is drawn as outlined paths. Use the supplied files instead of retyping it.
- Do not recolor, rotate, stretch, outline or add effects to the mark.
